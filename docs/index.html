图像对齐

页面配对不等于图像配准：选择页面后自动计算特征配准。未对齐前禁止迁移；偏移单位为 TARGET 像素。自动配准可识别画面特征，矫正横纵缩放、轻微旋转与剪切；不使用 AI 或 OCR。复杂非刚性变形建议桌面版。

未配准，选中页面后将自动计算

迁移 / 修复参数

左键拖动：透明底替换或挖孔替换；右键拖动：直接恢复日文原图。两种模式严格限制在画笔覆盖范围，画笔 2–240 px；[ / ] 调整大小。

「透明底替换」自动估计原图背景色，只清除疑似日文墨迹，并贴上不褪色的中文；「挖孔替换」以估计的原始背景色清除笔刷区域再迁移中文。非纯色背景会改用配准后的 SOURCE 局部纹理（不涂白），边缘做柔和过渡；也可主动选择「纹理直贴」。纹理移植可能带入 SOURCE 的扫描色差，请在叠加检查中先确保配准精确。两种编辑都会保存到工作区/导出，切换模式不会自动改写以前的笔画。右键可恢复原始日文。

使用提示

① 调整中日图片对应和偏移，查看对照。

⑤ 保存工作区 ZIP 可在下次继续编辑。
