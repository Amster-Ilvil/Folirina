测试日期：2026-08-11

输入为用户提供的同一漫画页：

- 日文原图：`real_pair_target.jpg`（仅测试时映射，不随包分发）
- 已正确嵌入中文的参考图：`real_pair_source.png`（仅测试时映射，不随包分发）

## v0.5 新路径

纯 `mask_replace` 模式会先运行页面配准，然后在配准置信度足够高时启用 **paired-diff extraction**：

1. 旧中文版 warp 到高清日文版坐标系；
2. 对两页做轻度抗压缩差分；
3. 将真实变化字符聚合成候选区；
4. 每个候选区吸附到源/目标两边的封闭白色气泡或文本框内部；
5. 未发生翻译变化的气泡、拟声词、装饰文字不会入选；
6. 同尺寸、近乎 identity 的页面走 `pixel-exact` 快速路径，避免 resize / feather / background normalize；
7. 实际变化但位于气泡白底边缘抗锯齿带的少量像素，通过 changed-fringe 只在同源 identity 快速路径内补齐；
8. 替换蒙版之外的高清日文像素完全不改变。

配准不够可靠时不会强行走差分提取，而是回退到 OCR / MangaLens / sidecar 的通用流程。

- SIFT 配准置信度：`0.999811`
- 内点率：`0.999634`
- 重投影误差：`0.000102 px`
- 自动检测实际翻译区域：`5`
- 应用替换：`5/5`
- QA error：`0`

自动找到的 5 个区域正好对应：

顶部 3 个未翻译的小气泡和画面中的日文拟声词均未被选择。

### 像素级结果

以用户提供中文图作为翻译区域真值：

- **替换蒙版内与参考中文图逐像素一致：100%**
- **替换蒙版外与高清日文原图逐像素一致：100%**
- benchmark 定义下的真实翻译变化像素重建率：**100%**
- 替换蒙版内：**100% 与中文参考逐像素一致**
- 替换蒙版外：**100% 与日文母版逐像素一致**
- 整页对参考中文图 MAE：`0.00357`
- 整页 PSNR：约 `60.02 dB`

整页并不强行复制参考中文 PNG：替换蒙版之外始终保留用户提供的日文母版，因此少量与“参考 PNG 编码/边缘像素”有关、但不属于翻译区域的差异会继续保留日文母版，这正是目标行为。

## 结论

对这组同源测试页，v0.5 已经达到：

> **翻译区域 100% 按参考中文图复现，同时非替换区域 100% 保留日文母版。**

这比“整页复制中文图”更严格，也比仅依赖 OCR 框更安全。

对于真正的“低清旧汉化 → 高清新版”场景，几何不再满足 identity，程序会使用现有的：

`SIFT / LightGlue / LoFTR → 气泡实例匹配 → 局部 bbox/ECC → 可选超分 → 目标 mask 裁切 → QA`

因此本次 100% 结果不能被错误解释为“所有不同版本都保证 100%”，但它验证了同源版本的最优路径已经正确实现。
