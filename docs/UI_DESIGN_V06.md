# v0.6 macOS UI

v0.6 延续 KCC-Kindle-CHS 的紧凑 PySide6 桌面工具设计：白色卡片、极浅蓝灰边框、单一淡蓝强调色、低层级阴影感、较大的漫画预览区和窄设置栏。

## 页面

1. **页面**：旧中文版 / 高清日文版 / 输出目录、自动配对、整册状态、处理路线、断点续跑和缓存开关。
2. **识别与配准**：OCR、页面配准、气泡结构、运行时 readiness、Apple MPS 与批量性能策略。
3. **替换工作台**：日文原图 / 旧中文版 / 最终结果 / 替换蒙版四种预览；右侧仅保留蒙版替换、局部对齐与超分的高频参数。
4. **出版输出**：最终图、工程 JSON、mask transfer layer/mask 与可编辑 ORA/PSD。

## 运行策略

- 省资源：较低 CPU 占用与 MPS memory fraction。
- 智能平衡：默认，适合大多数整册任务。
- 性能优先：增加 CPU 预处理/预检资源，但 MPS 深度推理仍受控串行，避免统一内存峰值。

运行时/模型状态探测是无副作用的：打开“识别与配准”页面不会因为状态刷新而导入大模型、创建环境或下载权重。
