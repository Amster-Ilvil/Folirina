Folirina Web · 原生 Python 引擎

GitHub Pages 可以免费打开，但纯浏览器无法直接运行桌面版的 Python / OpenCV / Qt / 可选 AI 模型。若要使用与桌面源码一致的手动区域配准和迁移，请在自己的 Mac 或 Windows 电脑运行原生服务，再用浏览器打开本地工作台。

启动

  1. 下载或克隆 Folirina GitHub 仓库，使用最新 main。
  2. 按桌面版的安装说明配置 Python 和依赖（包括 OpenCV、NumPy、Pydantic）。请在同一 Python 环境启动服务。
  3. 在 Folirina 仓库根目录执行：
    python tools/web_bridge.py
    Windows 如果没有 python，可尝试 py tools\web_bridge.py。macOS 通常使用 python3 tools/web_bridge.py。
  4. 打开 http://127.0.0.1:8765/。顶部出现“引擎：原生 Python”表示已连接。此模式下从该本地网址导入中日图片。

能力边界

原生网页模式使用桌面项目的 OpenCV SIFT/ORB 配准和同一套 region_composite.apply_region_action 手动区域函数：透明迁移、挖孔、Direct Patch、精准蒙版，另有右键恢复、克隆、画笔、ZIP 导出。尚未开放桌面完整版的 Koharu 自动检测、OCR、整册自动批处理、全部模式路由和高级 QA。这些功能仍请使用桌面程序。

本地服务器严格监听 127.0.0.1，不对外网开放，使用临时请求令牌。原始图片仅传到本机进程。不要使用端口映射、反向代理或公开访问方式共享此服务。关闭终端服务后，纯浏览器版依然可正常使用。

提示：需要公网免安装、无需服务端的朋友仍可使用 GitHub Pages Lite 模式；该模式使用简化算法，不保证与桌面引擎同等画质。大范围手动区域可能覆盖原作画线条；请先保存工作区并核对结果。
