# Folirina Web Lite v0.3.3 — 人工双掩码文字替换（免安装）

- 发布形态：纯静态网页，GitHub Pages 托管；本版功能无须 Python、本地桥接或 AI 模型。
- 设计原则：不把 SOURCE / TARGET 的候选差异直接判定为文字。分开编辑两个掩码，**先预览再明确同意**，不改变未覆盖区域。
- 当前完整度：这是可工作的**人工复核版**，不是 Folirina 桌面版完整自动 Direct Patch 端到端等价实现。

## 使用流程

1. 分别导入中日图片或 ZIP，核对页面配对、自动配准和「叠加检查」。
2. 点击「◉ 差异检查」，在目标图片上刷出需要检查的区域。
3. 转到「差异掩码」；绿 = SOURCE 中文候选，红 = TARGET 日文候选。
4. 右侧使用「+/- 中文绿笔」「+/- 日文红笔」逐一修正候选区域。右键在掩码视图可擦除红色候选。
5. 选择背景修补方式：默认 TARGET 局部邻域插值；可选配准后的 SOURCE 纹理（可能带来灰度/色彩接缝）。
6. 点击「预览修复」检查中文是否完整、日文是否清理、背景有没有被误伤。检查不合格，返回差异掩码继续修改。
7. 点击「确认应用掩码」后，该笔才加入正式编辑。可撤销、重做、保存工作区，导出 PNG 或整册 ZIP。

## 安全与质量边界

- 漫画原图保留不变；用户掩码 ROI 外必须 0 像素改动。
- 此流程必须手工修正候选，不允许未审阅、未预览的候选自动提交。
- 灰度网点、建筑线条、人物背景存在不可由局部邻域插值完美恢复的情况；成品需人工观察，不等同于桌面版 OpenCV 精修质量。
- 这版的「修补」不能恢复两版都被文本覆盖的真实底图细节；必要时使用克隆画笔手工修正。
- 原有免安装简化迁移、纹理直贴、配准和页面管理仍然保留。

- 浏览器：真实彩页第 09 卷第 0014 页，导入→配准→双掩码→修改→临时预览→应用→撤销/重做→导出 PNG/工作区 ZIP→重载工作区→整册 ZIP。
- 浏览器 JS 异常：0。
- 选区内改变 2,637 像素，选区外改变 0 像素（单个测试笔画，**不是**整页自动合格率）。
- 工作区重载后 PNG 字节一致，整册 ZIP 中的 PNG 字节一致。
- 节约空间：双掩码使用位打包和 base64，存储随选区大小而非原图分辨率增长。
- 单元测试：独立 target 清理、source 书写、严格 ROI 写入和 bitmask roundtrip。

## 部署

直接将 `docs/` 文件夹部署为 GitHub Pages 的 `main /docs`，确保 `reviewed_masks.js` 和缓存文件同步升级。无需 Node 后端。
