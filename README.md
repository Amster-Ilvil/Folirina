# Manga HD Translation Transfer

面向“旧版低清中文汉化图 → 高清日文原图”的出版级译文迁移与重新嵌字工具。

## 项目目标

输入两套同一漫画的页面：

- **旧中文版**：分辨率较低、已有中文译文，可能存在压缩、扫描偏移、裁边、旧字体与旧嵌字。
- **高清日文版**：画面质量更高、保留日文原文，需要清除日文并重新嵌入旧中文版中的中文译文。

输出应尽可能保留高清日文版的画面质量，同时让中文译文准确回到对应的气泡、旁白框、文本框和画外文字位置，并提供人工复核与可编辑工程数据。

## 核心原则

1. **译文内容优先，不直接依赖旧图像素。** 普通对白默认从旧中文版 OCR 提取中文文本，然后在高清原图上重新排字。
2. **先配准，再匹配文本。** 不把“按分辨率缩放坐标”当作主要对齐方式；先建立旧中文版到高清日文版的页级/局部几何映射。
3. **气泡与文本框是版面约束。** OCR 框只说明文字在哪里，气泡/旁白框的实例分割结果决定真正的可排版安全区。
4. **清字只作用于日文文字。** 尽量保护气泡边缘、网点、线稿、拟声词装饰和人物线条。
5. **低置信度必须进入人工复核。** 不静默猜测页配对、OCR、区域匹配或版式。
6. **无损中间数据。** 每页保留配准矩阵、文本区域、气泡 mask、清字 mask、OCR 候选、匹配置信度、排版参数和最终 QA 结果。

## 目标流水线

```text
旧中文版 ── 页面配对 ─┐
                    ├─ 全局/局部图像配准 ── 区域对应图
高清日文版 ─ 页面配对 ─┘

旧中文版 ─ 中文文本检测/OCR ─ 分组/阅读顺序 ─ 中文译文单元
高清日文版 ─ 日文文本检测 + 气泡/文本框分割 ─ 清字 mask ─ 高质量修复底图

区域对应图 + 中文译文单元 + 高清版气泡几何
                  ↓
        文本身份匹配 / 冲突检测
                  ↓
       气泡感知自动排字与字体拟合
                  ↓
        自动 QA + 人工复核编辑器
                  ↓
        PNG/TIFF + 工程 JSON/PSD
```

## 不采用的核心做法

- 仅按宽高比例 resize 旧版文本框后用 IoU 匹配。
- 只取页面中心一块模板做单一平移对齐。
- 默认把低清汉化图中的文字像素直接贴到高清图。
- 用大矩形直接涂白整个气泡。
- OCR 低置信度时仍自动输出“完成”。

## 第一阶段目标

先完成一个可测量的 **MVP Transfer Engine**：

1. 成对导入旧中文版与高清日文版。
2. 自动页面配对与页级配准。
3. 从旧中文版提取中文文本及文本区域。
4. 从高清日文版检测日文文本与气泡/文本框。
5. 建立跨版本文本区域对应关系。
6. 只清除高清版日文文本。
7. 在气泡安全区内重新嵌入中文。
8. 导出逐页 debug overlay 和结构化工程 JSON。

项目当前处于设计/基线阶段。
